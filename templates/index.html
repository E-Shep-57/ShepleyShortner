LinkShrink v1.0

What is this?

This application is a custom URL shortener that is similiar to Bit.ly and is designed to transform long, messy web addresses into clean, manageable shortcodes using a unique ASCII folding algorithm.

1. Create

Paste any fully-qualified URL. Our algorithm strips punctuation, converts to lowercase, and "folds" the ASCII values until the code is 8 characters or less.

START CREATING

2. Redirect

Once generated, your link is stored in our registry. Use the /go/<id> route to instantly redirect from Odin to your destination.
